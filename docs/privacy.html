MultiBotV2 Documentation DPA (AVV)

Privacy Policy

Last updated: August 2026 — Version 2.0

Plain-language summary: MultiBotV2 is self-hosted software. The person who runs the bot controls all data. No data leaves the server you run it on except for Discord's own API calls. Members can see and delete their data at any time with /data info and /data delete.

1. Data controller and processor

MultiBotV2 is self-hosted software. The organisation or individual that deploys and operates a MultiBotV2 instance is the data controller within the meaning of Art. 4 No. 7 GDPR. They determine the purposes and means of processing.

If you are a developer who provides MultiBotV2 as a service to other server operators, a Data Processing Agreement (DPA / Auftragsverarbeitungsvertrag) is required under Art. 28 GDPR. A template DPA is available at dpa.html in this documentation.

If you are running this bot solely on your own server for your own community, you are the sole data controller and no DPA is required.

2. What data is collected and why

2a. Automatically collected when the bot is used

  • Discord User ID — public identifier used to associate XP, economy, warnings, and per-user records with the correct account.
  • Discord Guild (Server) ID — used to separate all data between different servers on the same instance.
  • Timestamps — stored for rate-limiting, cooldowns, and streak tracking (e.g. daily rewards).

2b. Collected when specific features are used

  • Ticket content — conversations may be saved as transcripts. Configurable by the server operator.
  • Application answers — stored when a member submits a form, for staff review.
  • Moderation history — warnings, bans, kicks, timeouts, for audit purposes.
  • Birthday date — only if set via /birthday set.
  • Economy and XP data — coin balance, XP, level, message count.

2c. Only collected if explicitly enabled by the server operator

  • Message content — the message-logging feature (/server-backup messages enable) is off by default. If enabled, messages are stored for the configured retention period (default: 90 days).

3. Data storage and infrastructure

All data is stored in a SQLite database file (bot.db) on the server infrastructure chosen by the operator. MultiBotV2 does not use third-party databases, analytics services, or advertising networks.

⚠️ No GitHub synchronisation: The GitHub DB-sync feature (which periodically pushed the database to a GitHub repository) has been permanently removed from MultiBotV2. This feature posed a risk of unintentional public data exposure and constituted an international data transfer under Art. 44 ff. GDPR that was not adequately disclosed. Data persistence is now handled exclusively via the /bot-backup command.

Infrastructure-level logging

The hosting provider (e.g. Render.com) may log IP addresses at the infrastructure level as part of their standard access logging. This is outside the control of the bot application. The bot itself does not log or store IP addresses in its database. For details, refer to your hosting provider's own privacy policy.

4. Legal basis for processing (GDPR)

  • Legitimate interest (Art. 6(1)(f) GDPR) — moderation history, rate-limiting data, and server configuration are necessary for the legitimate interest of operating a safe Discord community.
  • Consent (Art. 6(1)(a) GDPR) — features that store additional data (birthday, applications, message logging) require explicit member or operator action to activate.
  • Contract performance (Art. 6(1)(b) GDPR) — economy and XP data are necessary to deliver the features members participate in.

5. Data retention

  • User data (XP, economy, warnings) — until the member runs /data delete or the operator purges it.
  • Ticket transcripts — until deleted by a server admin.
  • Moderation history — until deleted by a server admin.
  • Logged message content (if enabled) — automatically deleted after the configured retention period (default 90 days, configurable 1–3650 days or indefinitely).
  • Backup snapshots — until deleted by a server admin via /bot-backup delete.

6. Your rights under GDPR and equivalent laws

  • Right of access (Art. 15 GDPR): Run /data info in any server where the bot is active to see a summary of all data stored about you on that server.
  • Right to erasure (Art. 17 GDPR): Run /data delete to permanently and irreversibly delete all personal data stored about you on that server. Deletion is executed as an atomic database transaction covering XP, economy, warnings, tickets, logged messages, birthdays, notes, and all other per-user tables.
  • Right to rectification (Art. 16 GDPR): Contact the server operator for corrections to stored data that cannot be changed via the bot's own commands.
  • Right to restrict processing (Art. 18 GDPR): Contact the server operator.
  • Right to data portability (Art. 20 GDPR): The bot does not currently offer a machine-readable personal data export. Contact the server operator for a manual extract.
  • Right to object (Art. 21 GDPR): Contact the server operator to object to specific processing activities.

7. Children's privacy and minimum age

Discord requires users to be at least 13 years old globally. However, in Germany and several other EU member states, the minimum age for digital consent under Art. 8 GDPR is 16 years (or the applicable national age, unless parental consent is provided). MultiBotV2 does not implement age verification and relies on Discord's own age-gating mechanisms.

If your community is likely to include users under 16, the server operator should obtain and document appropriate parental consent or restrict the collection of personal data from those users. The operator is responsible for compliance with Art. 8 GDPR and national implementing legislation in their jurisdiction.

8. Gambling features

MultiBotV2 includes gambling mini-games (blackjack, slots, coin challenges). All in-game currency is virtual and has no monetary value. No real money is involved at any point.

Responsible-gaming disclosures are shown to users the first time they use gambling commands, and users must actively accept them before playing. Cooldowns and session limits are enforced to limit excessive use.

Important for server operators: If virtual currency earned through this bot is linked to real-world value outside of Discord (e.g. exchangeable for Minecraft in-game items with a real-money market), this may engage gambling regulations in your jurisdiction. That linkage is outside the control of this software. The operator is solely responsible for ensuring compliance with applicable gambling laws.

9. Contact and data requests

MultiBotV2 is self-hosted software. There is no central operator. Data-related requests must be directed to the administrators of the specific Discord server you are using. They are the data controller for their deployment.

10. Discord's own privacy practices

MultiBotV2 operates within Discord's platform. Discord processes data independently under its own Privacy Policy. MultiBotV2 only accesses data that Discord makes available via its Bot API.

11. Changes to this policy

This policy is updated when data-processing features change. The version number and date at the top reflect the most recent revision. The changelog is maintained in the repository.
